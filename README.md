# Автоматическая запись к врачу

Программа помогает автоматически поймать свободный талон на сайте [uslugi.tatarstan.ru](https://uslugi.tatarstan.ru).

Вы один раз выбираете полис, специальность, врача и время запуска. После этого программа сама проверяет сайт и пытается записать вас, когда появляются свободные места.

## Что нужно для работы

- Windows 10,11 или Linux(systemd);
- Python 3.12 или новее;
- установленный `uv`;
- доступ к интернету;
- учетная запись на сайте Госуслуг Татарстана.

## Первый запуск

Откройте PowerShell и выполните команды по очереди:

```powershell
git clone https://github.com/bizneskind-droid/GosuslugiRT.git
cd GosuslugiRT
uv sync
uv run config.py
```

Команда `git clone` скачает проект, `cd GosuslugiRT` перейдет в его папку, `uv sync` установит необходимые компоненты, а `uv run config.py` запустит настройку записи.

При первом запуске программа сама попросит войти на сайт. Введите номер телефона и пароль, после чего данные входа будут сохранены на компьютере.

Пароль не записывается в программу. Файл с сохраненным входом нельзя передавать другим людям или публиковать в интернете.

## Как настроить запись

После входа программа по очереди попросит выбрать:

1. нужный полис;
2. специальность врача;
3. одного или нескольких врачей;
4. нужно ли запускать проверку автоматически;
5. время запуска.

Например, чтобы программа начала искать талон в 7 утра, выберите автоматический запуск и укажите `7:00`.

После настройки Windows сама запустит программу в указанное время. Компьютер может быть разбужен автоматически, если это разрешено настройками питания Windows.

## Как работает поиск

В назначенное время программа:

- подключается к сайту;
- проверяет выбранный полис;
- проверяет выбранных врачей;
- ждет появления свободных дат;
- выбирает случайный свободный талон;
- отправляет запрос на подтверждение записи.

Если свободный талон найден, в журнале появится дата и время записи.

Программа не выбирает конкретное время приема. Дата и время свободного талона выбираются случайно из доступных на сайте.

## Если нужно изменить настройки

Снова запустите:

```powershell
uv run config.py
```

Выберите новый полис, специальность, врача или время запуска. Для нового дня автоматическую задачу также нужно создать заново.

## Если нужно проверить сразу

Можно запустить поиск вручную, не дожидаясь времени в планировщике. Значение времени должно совпадать с тем, которое было указано при настройке:

```powershell
uv run main.py --time 7:00
```

Такой запуск удобен для проверки соединения, входа и выбранных настроек.

## Как понять результат

Журнал работы находится в папке `logs`, файл называется `record.log`.

При успешной записи появится сообщение:

```text
Запись успешно подтверждена
Дата и время: 11.09.2026 14:00
```

Если талонов пока нет, программа будет повторять проверку и писать сообщения о том, что свободные даты не найдены.

Если возникла проблема с интернетом или сайтом, она также будет записана в журнал.

## Важные моменты

- автоматическая задача запускается один раз, а не каждый день;
- после отмены записи настройку нужно запустить заново;
- если данные входа еще не сохранены, `config.py` сам запустит авторизацию;
- выбранный врач должен быть доступен в выбранной специальности;
- программа записывает только к тем врачам, которых вы выбрали при настройке;
- перед запуском убедитесь, что компьютер подключен к интернету;
- для пробуждения компьютера Windows должна разрешать таймеры пробуждения.
